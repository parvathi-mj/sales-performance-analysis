# Sales Performance Analysis and Interactive Dashboard

## Project Overview
This project explores sales performance using interactive dashboards developed with Microsoft Excel, Tableau, and Power BI.

## Objectives
- Analyse sales, profit, quantity, and discount metrics.
- Compare sales performance across regions and product categories.
- Identify trends over time.
- Present business data through interactive visualisations.

## Tools and Technologies
- Microsoft Excel
- Tableau
- Microsoft Power BI
- Data Visualisation
- Business Intelligence

## Dashboard Features
- KPI summaries for key business metrics.
- Regional and category-wise sales analysis.
- Product and subcategory comparisons.
- Time-based sales trends.
- Interactive filters and slicers where implemented.

## Project Files
The repository contains the available dashboard files organised by tool.
